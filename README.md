# K2-kamp

Текущая установленная адаптация KAMP **2.3** для **Creality K2 Plus (F008), прошивка 1.1.7.0**. Основной сценарий: **Creality Print 7.3 → локальная сеть → принтер с root**.

Этот репозиторий сохраняет рассмотренные и загруженные на принтер файлы. Это снимок конкретной конфигурации, а не универсальный установщик для любых прошивок K2.

## Что реализовано

- Адаптивная сетка по EXCLUDE_OBJECT_DEFINE, переданным слайсером до START_PRINT.
- Штатный расчёт KAMP: для небольшой модели минимум 3×3; исходная полная сетка 9×9. Поле вокруг объектов — 5 мм, случайное смещение точек выключено.
- Карта адаптивного замера существует только в памяти сеанса. Исходный профиль default сохраняется.
- Проверка совместимости обработчиков Klipper до допуска измерения; защита карты от штатных команд и update_mesh во время сеанса.
- При фатальной ошибке сначала останавливается подача файла, затем выполняется очистка состояния. Отклонённая внешняя команда не сбрасывает карту продолжающейся печати.
- Повторная NOZZLE_CLEAR из добавленной подготовки удалена. При prepare=0 остаётся штатная первая очистка; при prepare=1 используется выполненная внешняя подготовка Creality.
- Удалён лишний предварительный G28 Z; сохранены принудительная оптика, выравнивание двух Z на прогретом столе и заключительный поиск Z. После принудительного поиска явно потребляется запрос ZDOWN, чтобы он не повторился после выравнивания.
- Команды CFS, продувка и стартовая линия слайсера сохранены. Адаптивная продувка KAMP не включена.

## Состав

`payload/` повторяет абсолютные пути файловой системы принтера. Все семь файлов побайтово соответствуют установленной версии; их SHA-256 приведены в manifest.json.

- `payload/mnt/UDISK/printer_data/config/printer.cfg` и `gcode_macro.cfg` — снимки изменённых основных конфигураций.
- `payload/mnt/UDISK/printer_data/config/KAMP/` — макросы и настройки.
- `payload/usr/share/klipper/klippy/extras/restore_bed_mesh.py` — адаптер.
- `patches/stock-to-2.3.diff` — полный diff от исходного снимка устройства.
- `patches/2.2-to-2.3.diff` — последняя узкая правка.
- `tests/` — 49 локальных регрессионных тестов и сохранённые открытые исходники прошивки, на которых они основаны.
- `docs/reviews/` и `docs/validation/` — заключения Astra и результаты проверок без сырых журналов и реквизитов доступа.

## Установка и обновление

Перед применением сверить модель и прошивку, сохранить собственную конфигурацию и профиль default. printer.cfg содержит параметры и калибровку конкретного экземпляра; переносить его целиком на другой принтер не следует. Зависимости штатных include, которые уже есть на устройстве, этот репозиторий не заменяет.

Для существующей установки 2.2 последняя правка меняет только gcode_macro.cfg. Перед заменой сравнить его SHA-256 с `before_sha256` в `docs/validation/revision-2.3-manifest.json`. Если он отличается, сначала вручную сопоставить конфигурации. После записи сверить конечный хеш.

Для установки от исходной прошивки использовать полный diff как описание интеграции: добавить секцию restore_bed_mesh, include KAMP и обработчик on_error_gcode; внести изменения макросов и скопировать четыре KAMP-конфига и адаптер. Порядок полного diff и файлы payload служат эталоном; автоматическая загрузка на неподтверждённую прошивку не предусмотрена.

Изменять конфигурацию на свободном принтере. После остывания сопла выполнить полное ручное выключение/включение: на проверенном устройстве ранее наблюдалась ошибка motor_control после программного RESTART. После загрузки проверить Klipper ready, restore_bed_mesh.ready=true, пустой error, неактивные флаги сеанса, motor_ready=true и сохранность default. Протокол проверки загрузки 2.3 сохранён в docs/validation.

Затем пользователь запускает контрольную печать из Creality Print по LAN. Проверить отсутствие повторной NOZZLE_CLEAR, порядок оптики → горячий tilt → поиск Z → одна адаптивная сетка, штатную загрузку CFS и первый слой. Физический результат правки 2.3 и фактическое сокращение времени ещё предстоит подтвердить этим запуском.

## Ограничения

Восстановление после потери питания не поддерживается: временная карта после перезагрузки утрачена; параметр ISCONTINUEPRINT отклоняется независимо от его значения. Функцию восстановления необходимо отключить в интерфейсе. Обычная пауза без перезагрузки обрабатывается отдельно с сохранением карты.

MESH=0 не поддерживается. Для ручной полной калибровки на свободном принтере предусмотрена команда KAMP_FULL_BED_CALIBRATE. Обычные G29 и ранние вызовы калибровки от Creality отложены до защищённого START_PRINT; прежняя семантика ручного G29 изменена.

Закрытые части prtouch_v3 и MCU не становятся аппаратно проверенными из-за успешных локальных тестов. Адаптер отказывает при неизвестной схеме обработчиков вместо ослабления проверки.

## Проверка локально

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -p test_kamp.py -v
```

Тесты не соединяются с принтером. Они используют сохранённые реализации команд и подменяют физическое измерение и кинематику. Последний результат: 49 тестов, ошибок и падений нет.
